## 每周投入和学习方法

学期核心 25 小时：学习与项目 14 小时，算法 6 小时，计算机基础 3 小时，复盘与岗位研究 2 小时。额外最多 5 小时用于补漏。寒假额外 10–15 小时主要投项目、联调、评测；春季将项目中的 3–5 小时转给面试准备。

每日只设一个主要交付，每周最多三个目标。视频阅读必须配套动手产出。基础初期可将基础知识时段用于列表、作用域、栈和复杂度，随后转向 HTTP、SQL、网络和操作系统。前两周不要求精读大量面经；复盘时段用于发现编码问题。

算法统一 Python：前期每周 2–3 道新题，基础稳定后 4–5 道，并安排旧题复习。已有两数之和、移动零用 Python 重写计为复习，不计新增。HOT 100 是核心题单，按题型推进，不以背代码或刷题数认定掌握。先独立思考 20–30 分钟，再看提示，关闭参考重写，隔几天复写并解释复杂度。

AI 可用于解释、提示和排错。先贴自己的尝试和具体问题；自己实现核心功能，再用 AI 审查。简历里的功能必须能独立修改、解释。连续两周投入明显低于预算，按实际时间重排；考试周减少新内容，保留短时编码与复习。

## 技术范围

基础包括 Python、SQL 与 MySQL、FastAPI、SQLAlchemy、Git、HTTP、Linux、Docker、并发与异步基础、操作系统和网络。需要时再学 Redis、后台任务队列、向量检索。

Agent 先用托管模型接口，自己写工具循环；之后只引入一个编排框架。模型密钥从环境变量读取，不上传到仓库。先理解上下文、工具调用和不确定性，无需先学完深度学习或训练模型。多 Agent、MCP、长期记忆、微调、Kubernetes 不列为默认前置。

## 求职执行

1 月建立 Notion 中的岗位记录，3 月开始每周投递 5–10 个符合条件的岗位，岗位不足不凑数。明确写明 2029 届、5–6 月到岗、每周 4–5 天、连续至少 3 个月。核对每个项目是否接收毕业年份和到岗时间。

搜索 AI 应用、Agent 工程、智能体研发、AI 工具与相关后端。算法岗位按职责核对，不默认准备强化学习、模型训练或论文研究。选择 Python 意味着减少完整 Java 技术栈岗位覆盖，换取 Agent 实践深度。

反馈少先查资格、到岗、简历；技术面失分按实际问题补课。每次面试留具体问题、回答缺口和后续练习。offer 的薪资以正式沟通或文件为准，按出勤天数和住宿通勤计算结余；当前未确定具体生活费预算。

开始投递前检查：能独立新增一个工具并测试；能解释提交、执行、保存状态、返回结果的全流程；能讲清两个失败案例及改进证据；能现场写常见算法题；能回答项目相关的索引、事务、HTTP、进程线程和异步问题。短板继续补，不等所有技术学完才投。
